# 待定事项

本文列出需求整理中已经识别、但尚未确定的问题。每一项确定后，结论写入对应的需求文档或规格说明，并从本清单移除。每一项末尾注明最晚在哪个阶段定下来。

## 1 产品范围

1. Linux 桌面端。首版不做，支持时间待定。系统集成服务已经按平台分开实现，加 Linux 只需要再写一份。首版发布后按用户需求定。

## 2 运行参数

1. 默认值。包括定时触发的截屏间隔、像素比对的容差、整张重新识别的变化面积阈值、判定段落与变化区域相邻的距离、各节点超时、批次总时限、事件触发后的等待时长、显示设置中的最小字号、观看端画面的压缩参数，以及运行协调器在后台时发起运行的电脑断连的宽限期；规格说明中标为"默认值待定"的其他参数也在这里一并确定。原型阶段用同一组样本，测不同取值下的延迟和调用量，再定。

## 3 验收合格线与默认键位

1. 验收合格线。规格说明 [验收与测试](../spec/16-acceptance.md) 定义的各项指标，在原型阶段用验收样本测出基线后确定合格线。
2. 默认快捷键。全局快捷键的默认键位在两个平台上实测，避开系统和常用软件已经占用的组合后确定，规则见规格说明 [桌面端](../spec/12-desktop.md) 2.2。原型阶段定。
